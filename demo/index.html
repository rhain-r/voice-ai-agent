Voice AI Agents: Live Demo

Both agents run entirely in your browser: the browser handles speech recognition and speech, and the agent logic is the repository's own Python code ported to JavaScript. No account or API key is needed; the few turns that need Claude in the full app are labelled as such.

Kitchen Companion

Load a recipe, press Start listening, and talk to Chef. Begin with "Chef", as in "Chef, next step"; for eight seconds after Chef speaks you can reply without it, and anything else is ignored as overheard conversation.
